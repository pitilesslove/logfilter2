# 01. 프로젝트 개요 및 목표

## 프로젝트명

K8s Log Viewer

## 목적

Kubernetes 환경의 Pod 로그를 실시간으로 조회하고, 다양한 조건으로 필터링·검색·탐색하는 웹 기반 로그 뷰어.
운영 담당자나 개발자가 브라우저에서 별도 설치 없이 접속하여, kubectl 명령을 직접 치지 않고도 Pod 로그를 실시간으로 확인할 수 있다.

## 배경

- Kubernetes 클러스터 운영 시 `kubectl logs -f` 명령으로 로그를 확인하는 것이 일반적이나, 터미널에서는 필터링·검색·하이라이트가 불편하다
- 기존 로그 분석 도구(ELK, Loki 등)는 설정이 복잡하고 인프라 비용이 크다
- Spring Boot, Logback, DX 등 다양한 로그 포맷이 혼재하는 환경에서 통합 뷰어가 필요하다
- 이전 버전(Java Swing / Kotlin TornadoFX)의 데스크톱 앱을 웹으로 전환하여 접근성을 높인다

## 대상 사용자

- Kubernetes 클러스터 운영자
- 백엔드 개발자 (Spring Boot, Java 애플리케이션 운영)
- DevOps/SRE 엔지니어
- QA 담당자 (장애 로그 분석)

## 핵심 요구사항

1. **K8s 클러스터 연결**: Context/Namespace/Pod 선택 후 로그 조회
2. **실시간 스트리밍**: SSE를 통한 `kubectl logs -f` 실시간 로그 수신
3. **다중 필터링**: 로그 레벨, 키워드(포함/제외), 클래스명(포함/제외) 필터
4. **하이라이트 & 검색**: 키워드 하이라이트, F3/Shift+F3 네비게이션
5. **대용량 처리**: 가상 스크롤로 수만 건 로그를 끊김 없이 표시
6. **다중 로그 포맷**: Spring Boot, DX, Logback(traceId), 일반 로그 자동 감지 파싱
7. **로컬 파일 지원**: 로그 파일 업로드하여 동일한 필터링 UI로 분석
8. **로그 내보내기**: 필터링된 로그를 텍스트 파일로 다운로드

## 제약 조건

- **단일 HTML 프론트엔드**: 프레임워크 없이 순수 HTML/CSS/JavaScript로 구현 (빌드 단계 없음)
- **kubectl 의존**: K8s 통신은 서버에 설치된 kubectl CLI를 통해 수행
- **단일 Pod 조회**: 한 번에 하나의 Pod 로그만 조회 (멀티 Pod은 향후 과제)
- **한국어 UI**: 모든 라벨, 버튼, 메시지를 한국어로 표시
- **인증 없음**: 현재 버전은 별도 인증/권한 관리 없음 (kubectl 설정에 의존)
